# Changelog

## 0.2.0 — 2026-09-14

- Guarantee that every returned hint is directly applicable and fix Issue #1.
- Validate puzzle dimensions, identifiers, positions, targets and snapshot bridge records.
- Add canonical candidate topology and contradiction analysis.
- Add deterministic propagation, bounded complete search and none/unique/multiple classification.
- Add explainable smart hints, puzzle assessment and reproducible seeded generation.
- Add backward-compatible `BRIDGELAB2` snapshots and four new browser APIs.
- Replace the JavaScript rule fallback with MoonBit as the sole rule authority.
- Expand the site to a 12-level Play / Solve / Create workbench.
- Add keyboard editing, responsive layouts, reduced-motion support and focus management.
- Add 30 MoonBit tests, Node contract tests, desktop/mobile Playwright tests and reproducible CI gates.

## 0.1.0 — 2026-09-12

- Initial MoonBit rules core, three-level Web demo, CI and GitHub Pages deployment.
